# NetDoc-Pro

**Network Infrastructure Management & Documentation System — Local / Offline**
**سیستم مدیریت و مستندسازی زیرساخت شبکه — محلی و آفلاین**

---

## 🇬🇧 English

NetDoc-Pro is a local, offline tool for documenting and organizing network infrastructure projects. It is designed for network engineers and contractors who need a structured way to record, categorize and track network implementation work — without depending on any cloud service.

### ✨ Highlights

- 📁 **Structured documentation** — record network implementations in an organized, categorized way
- 🌐 **Bilingual UI** — full English and Persian (فارسی) interface
- 🔌 **100% offline** — everything runs locally; no internet connection or external service required
- 🪶 **Lightweight** — runs as a standalone local application

### 📦 Download

Ready-to-use packages are available in this repository:

| Package | Language |
|---|---|
| [`NetDoc-Pro-v1_4_1-English.zip`](NetDoc-Pro-v1_4_1-English.zip) | English |
| [`NetDoc-Pro-v1_4_1-Persian.zip`](NetDoc-Pro-v1_4_1-Persian.zip) | فارسی (Persian) |

### 🚀 Getting Started

1. Download the package for your preferred language (see the table above).
2. Extract the ZIP file.
3. Run the application locally — no installation or internet connection is needed.
